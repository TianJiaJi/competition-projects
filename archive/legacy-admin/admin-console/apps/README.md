# 应用目录

游客大屏与园方监控 Mock 已实现，其余端仍为职责说明。

| 应用 | 职责 |
| --- | --- |
| `mobile/` | 游客个人服务、二维导览、预约凭证、问答与聊天 |
| `ops/` | 三维运营沙盘、指标、预警与调度结果 |
| `visitor/` | 公共触控导览、景点与设施查询 |
| `admin/` | 内容与业务管理、场景控制、步骤跳转和演示重置 |
| `gate/` | 前线开始处理、完成反馈及处置记录（未实现） |
| `server/` | 统一 API、数据、时间、消息与外部模型代理 |

五个前端后续独立启动、构建和部署。应用间不导入彼此源码，公共能力经 `packages/` 复用。具体边界见 [架构方案](../docs/工作区与容器编排架构-V1.0.md)。
