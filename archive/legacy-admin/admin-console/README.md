# 智慧景区演示系统工作区

已完成第一版游客大屏模拟沙盘：Vue 3 页面、Three.js 体素地形、客流热力、设施查询、双向步行选路及山顶索道返程。当前使用明确标注的样例数据。

**游客大屏与园方大屏完整 Mock 原型已实现。手机端、后台、前线人员处置终端、后端和人脸识别尚未实施。**

## 启动游客大屏

需要 Node.js 22.12+（本轮使用 24）与 Corepack / pnpm。

```sh
pnpm install
pnpm dev
```

默认地址 `http://localhost:5173/`；同一局域网可使用启动日志中的 Network 地址。运行 `pnpm test`、`pnpm test:e2e`、`pnpm typecheck` 和 `pnpm build` 验证；浏览器测试需要 Playwright Chromium。

常开测试地址：`http://localhost:5173/?alwaysOpen=1`。仅在演示数据模式生效，持续保持开园客流、停车场开放与索道运行，日期时间正常更新，维修及养护状态保留。去掉参数恢复按营业时间模拟；真实接口数据不受此参数影响。

游客端已于 2026-09-11 完成前端归档，全部点位、路网、样例快照与交互口径见 [游客端数据清单](apps/visitor/docs/数据清单与交互约定.md)。

数据模式、接口预留及本轮边界见 [游客大屏实现说明](docs/游客大屏原型实现说明-V1.0.md)。

## 目录用途

| 目录 | 用途 | 当前状态 |
| --- | --- | --- |
| `apps/` | 手机、双大屏、后台、核销及后端应用 | 游客大屏已实现，其余仅职责说明 |
| `packages/` | 接口契约、客户端、视觉基础、景区地图共享能力 | 已实现游客大屏所需共享能力 |
| `assets/` | 图片、字体、模型及来源记录 | 仅管理约定 |
| `docs/` | 当前方案、原始 Word、历史归档 | 已整理 |
| `infra/` | 后续镜像、Compose、Kubernetes 和穿透配置 | 仅规划说明 |
| `scripts/` | 后续开发、校验、构建与部署辅助命令 | 仅规划说明 |
| `experiments/` | 临时原型与效果验证 | 仅管理约定 |

`.local/` 用于本机验证截图等临时产物，不作为版本化目录。本轮安装了前端依赖，未构建容器、创建数据库或修改服务器。

## 当前确定的方向

单仓库、五个独立前端、单实例 Node.js 后端；优先快速原型和清楚的模块边界。后续业务运行在现有两节点 Kubernetes 集群，香港节点负责 HTTPS 与穿透；本机选用 Docker Desktop。域名使用 `starhusk.com`，香港节点尚未购买。

## 园方大屏

运行 `pnpm dev:ops`，访问 http://localhost:5175/；样式检查使用 http://localhost:5175/?preview=1 切换完整 Mock 快照。`pnpm build:ops` 构建，`pnpm test:ops` 验证。产品改为人脸识别入园，原核销终端改为前线处置终端；园方只读、人工调度、前线反馈结案。详见 [园方说明](docs/园方大屏实现说明-V1.0.md)。
