# 游客大屏原型实现说明 V1.0

日期：2026-09-11。依据本任务确认的游客端大屏布局与交互方案实现。

## 本轮范围

只实现游客大屏及其依赖的共享能力。`apps/mobile` 保留原说明文档，没有新增手机页面。手机导览、真实后端、全天数值仿真、容器和发布均不在本轮实施范围。

虚构景区暂名“青岚山境”。地形和建筑为代码生成的可交互体素原型，具体景点造型仍可继续调整。当前色彩、布局和三维数据均可在现有实现上迭代。

## 已实现行为

- 完整体素地形、双向环形主路和景点短支路；体素门楼、景观亭、商业街、补给点、三处停车场及索道。
- 默认无景点名称、无热力；选点出现名称与高亮，右侧展开状态和路线优先的详情。关闭区域始终标灰。
- 地形材质按世界坐标混合区域热力，旋转与缩放时仍贴合地形；图例区分区域客流与设施负载。
- 点位图标、景点与设施列表、分类和名称查询；公告全文及定位、环境详情。
- Dijkstra 最短步行路径只使用可通行路段，支持更换预设起点。关闭目标、未知状态、断路和同起终点有明确结果。
- 山顶到出口商业区的下行索道为独立返程选项；索道模式明确包含接驳步道，其他查询默认步行。
- 空闲满 120 秒重置视角、面板、热力、起点与路线；最后 10 秒倒计时可取消。
- 大屏窄视口重排；竖向触控屏改为底部详情。减少动态效果停用背景装饰动效；持续低帧率时降低像素比、阴影与玻璃效果。

## 数据与接口

默认 `VITE_DATA_MODE=sample`。样例是前端预置公开快照，每 10 秒更新版本和时间；并非已实现全天仿真服务。时间显示使用上海时区；示例开放时段随时间变化。商业区使用所在区域的人数口径，不另算一遍客流；总在园与区域人数、总停车余位与停车场数据保持一致。

`packages/contracts` 定义公开点位、区域、路网、设施状态、快照及路线结果。`packages/scenic` 的默认入口仅含数据和纯逻辑，Three.js 从独立的 `/three` 入口加载。

预留真实连接模式：

- `GET /api/public/snapshot` 返回 `PublicSnapshot`；必要字段运行时检查，不接受畸形数据。
- 同源 `/ws` 作为刷新通知，收到消息或重连后重新读取快照，并有定时重试。
- 请求超时或断线会显示未知状态，不能冒充零值或切回样例成功。
- 本轮未实现该后端接口，因此使用 `live` 模式时连接失败是预期状态。

二维码仅提供大屏侧预留：未来在 `apps/visitor/.env.local` 配置 `VITE_MOBILE_URL`。普通点位使用 `point` 参数；路线使用 `from`、`to`、`mode`，只携带公共点位标识。默认未配置地址，不生成假链接。尚未做真实手机扫码接续验收。

支持浏览器实验性 `document.modelContext` 时，注册 `configure_scenic_view`，复用选择点位与热力开关；不支持时跳过，不影响页面。已在当前内置浏览器验证注册、有效点位联动及无效点位拒绝后保持原状态。

## 运行与验证

```sh
pnpm install
pnpm dev
pnpm test
pnpm typecheck
pnpm build
pnpm test:e2e
```

首次运行浏览器测试时如未安装对应浏览器，执行 `pnpm exec playwright install chromium`。

单元测试覆盖双向短路、封路绕行与不可达、关闭或未知目标、索道单向返程、人数口径、数据验证、链接参数及断线恢复。浏览器测试覆盖 1920×1080、1280×800 与 720×1080 的页面交互、热力、选点、缩放、返程切换、关闭目标、减少动态效果与空闲恢复。

本机验证截图位于被忽略的 `.local/qa/`。尚未验收真实触控硬件、实际浏览器缩放比例、30 分钟运行稳定性及完整跨端后端同步。
