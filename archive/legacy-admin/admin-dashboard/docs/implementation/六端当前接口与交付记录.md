# 六端当前接口与交付记录

更新日期：2026-09-13。本文件记录当前在线实现，不将原型能力或计划自动记为完成。统一业务实现位于 `apps/server/src/platform`，共享类型位于 `packages/contracts/src/platform.ts`。旧专项接口文档中与本文件冲突的地址、登录、任务状态及演示控制流程不再用于新在线客户端。

## 运行与连接

Node.js 24、TypeScript、PostgreSQL 17。迁移与本地核验见 [PG联调记录](PG迁移与本地联调-2026-09-13.md)。`pnpm dev:server` 启动 8787；游客大屏5173、管理员5179、园方大屏5175、游客H5 5176、前线5177、演示控制5178。各端使用对应 `pnpm dev:*`，游客大屏用 `pnpm dev`。构建小程序用 `pnpm build:mobile`。

新业务库默认 `.local/scenic-platform.sqlite`，新问答库默认 `.local/scenic-platform-qa.sqlite`。可分别通过 `SCENIC_PLATFORM_DB_PATH`、`SCENIC_DB_PATH` 覆盖；旧库不导入、不删除。游客新缓存键为 `qinglan-mobile-platform-v2`。

请求前缀 `/api/v1`。登录后使用 `Authorization: Bearer <token>`；运行通过 `X-Run-Id` 绑定，省略则选择当前展示运行。写请求带8—128字符 `Idempotency-Key`；任务、OA、订单、已存在内容带 `expectedVersion`。响应使用现有统一 `data/meta` 或 `error/meta` 封装，响应头提供 `X-Run-Id`、`X-Revision`。WS `/ws?app=<端>&runId=<运行>` 只广播失效通知，客户端重新获取快照；断线显示错误并重试。

两种数据大屏免登录。只读 `/screens/ops` 提供任务展示，但公开公告只含游客公告；敏感管理写入仍需管理员身份。旧 `/auth/experience` 默认410，游客应注册登录；仅显式 `SCENIC_LEGACY_EXPERIENCE=1` 可使用旧体验入口。

补充机器契约：[模拟员工与公告生命周期 OpenAPI](../openapi/platform-lifecycle-v1.1.json)。全量旧OpenAPI的迁移仍待完成，不能与本文件未实现项混用。

## 后续确认覆盖

2026-09-13 新增“模拟员工处理告警”覆盖原先“场景不自动领取和结案”的决定；OA审批依然人工。默认开启，30—60业务秒后领取未分配任务，再过2—5业务分钟反馈完成。时长从任务ID确定，结果与审计入库。人工先领取的任务不被接管；待审批OA阻止自动完成。演示终端提供启停开关。完成任务不直接改人数、车位、索道队列及设施状态；同轮持续异常不重复发告警。

公告按业务时间到期：快照和公告列表即时过滤，到期推进时标为expired，WS通知各端重读。暂停回放会暂停业务有效期。普通人工公告默认1业务小时，恢复提示默认10业务分钟，可配置。游客列表移除过时项，管理员保留历史记录。拥挤告警完成后仍异常时继续提示游客，实际恢复才转恢复提示。管理员撤下的关联公告不会自动重发。公开文案使用“较拥挤”“车位较紧张”“候乘人数较多”，不显示“监测值”。

数值显示小数固定两位，整数保留整数，未知值显示“—”；共享 `format-number.ts` 用于主要连续指标，百分比和路线距离两位。不对账本或仿真中间量做显示舍入。

## 数据分工与已知边界

自动数值：游客批次、到离园、区域分配、车辆、卫生间占用释放、索道排队在途、环境和历史。账本最终量守恒，随机值只用于需求与时长。背景预约当前为只读聚合批次；预测当前为均值外推。完整背景生命周期、分停车场流率、回程大巴泊位及全部数值方案尚未完成，不能标记高拟真整体验收通过。

自动业务：阈值告警、检修任务、关联公告、任务统计、模拟员工处理记录。LLM：模拟游客聊天与文字审核、向导问答；已生成消息持久化，模型真实端到端验收待完成。知识发布版本尚需完整接入RAG与会话历史管理。

一次性数据：共享点位路网、容量、24篇资讯指南、知识规则、10个演示账号。人工数据：管理员维护内容/配额/设施/检修及审批复核；前线领取、申请、反馈；游客注册、预约、发言、举报申诉、收藏路线；两种大屏只读。控制端人工选择场景、时间和事件。

未完全确定或尚待校准：全量背景预约生命周期、随机数值告警合法需求注入、六场景细事件表、游客离园与卫生间排队放弃耦合、索道批次返程细节。新聊天频率默认每真实分钟 `2×min(1,在园人数/8500)`、最多2条；失败跳过；只对当前展示且未暂停运行生成。随机现场类别当前等权，指标类注入尚未完成。不得把尚未实现的公式写作已校准。
