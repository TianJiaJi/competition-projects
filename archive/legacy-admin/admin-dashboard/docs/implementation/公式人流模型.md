# 公式人流模型（v4）

人流统计由实际闸机入园量的分钟桶生成，不保存每个游客的位置、不执行寻路，也不预跑个体游览行为。已有闸机、停车、卫生间和索道业务仍按原有业务时钟记账。

## 参数

时间充足时，85% 入园量分配到完整环线：入口、溪谷、竹林、峡谷、山顶、瀑布、湖畔、林间、商业、出口。各段含行走和停留的时间为 4、24、22、22、30、25、25、22、20、6 分钟。

其余入园量分别以 5% 进入溪谷、竹林、湖畔短线，基准时间为 60、90、90 分钟。短线按已有路径各段长度分配时间，折返入口的路线随后接商业区和出口。

快、普通、慢三档的时间倍率为 0.85、1、1.2，权重为 25%、50%、25%。每分钟按该分钟结束时至 19:00 的剩余时间筛选可完成的模板，再归一化。17:00 停止入园。完整环线的 85% 是入园选择比例，不是任意时刻在园人数比例；全线游程更长，因此在园占比通常更高。

## 人数与记账

区域质量为分钟入园量、模板权重和游程占用核的乘积之和。核在各段末尾最多两分钟内线性过渡，最后一段过渡到离园。核在模块加载时按十秒采样预计算，读取时支持插值。

仅查询最近最多 241 个分钟桶；更早的游客已全部离园。累计离园人数向下取整，剩余人数按最大余数法分配到区域，保证入园减离园等于在园、区域合计等于在园。真实订单在园人数继续单独叠加到入口区域，不受模拟离园影响。

停车返回时间使用入园时可用模板的加权平均游程，只用于车辆归还。索道候乘、运送独立记账，不决定公式人数何时离园。商业与出口使用独立阶段，区域口径仍都属于 Z0。

## 地图代表点

最多 320 个代表点按路线、快慢档和阶段的质量分层选取。固定种子定义代表点的分钟、分钟内出生偏移和抽样优先级；同一编号的位置是业务时间的函数，不因刷新重新随机。统计没有用这些抽样点反推人数。

代表点在每段后部减速，沿已有步道分散经过景点入口，不聚到建筑中心。输出未来一分钟轨迹时包含道路顶点和速度转折点，因此前端线性插值仍沿道路。代表点只展示人流，不对应真实游客，也不需要永久维持同一批代表点。

## 兼容与验证

v3 运行在首次加载时、事务内升级，无需推进暂停时钟。将现存当日客群的入园时间聚合成分钟桶，已离园人数作为基线；旧版已移除客群的入园时刻无法恢复，不虚构历史。保留车辆和索道业务记录、实际订单及业务时间。跨日清空当日桶。

单元测试覆盖权重、路线顺序、时长、晚入园、占用核过渡、整数守恒、跨日、迁移幂等、索道与停车解耦、代表点确定性、连续轨迹及固定查询窗口。浏览器测试提供早晨、中午、傍晚三种地图截图。
