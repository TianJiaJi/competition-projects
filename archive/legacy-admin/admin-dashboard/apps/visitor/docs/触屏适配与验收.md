# 触屏、镜头与开场适配

2026-09-12。游客终端使用同一套页面和公共材质，通过 CSS 视口尺寸适配 16:9 触屏电脑、横屏及竖屏平板。保留鼠标、键盘和 Mac 触控板；不依据触屏能力切换成另一套样式。手机只保持页面可打开、按钮可到达，不另做手机产品。

## 单指操作与布局

- 常规按钮、输入框、选择器、折叠标题至少 44 CSS px 高。无需悬停、右键、双击或双指即可完成列表、筛选、搜索、详情、路线、天气、公告及手机导览操作。
- 单指拖动沙盘旋转，点击加减缩放，“看全景”平滑恢复默认镜头；鼠标拖动、滚轮和触控板保持可用。多指缩放沙盘仍支持，不属于页面缩放。
- 长卡片内部单指纵向滚动，筛选条单指横向滚动；从列表切入详情或打开新主面板时滚动位置归零，不继承列表滚动偏移；拖动或取消触摸不作为点位点击，多指手势结束不误开详情。
- 画面使用 `100dvh`，避免低高度设备沿用旧最小高度而截掉底部按钮。窄平板保留手机导览入口，短屏图例与左侧缩放按钮错开；手机底部操作条可以单指横向滑动。
- 右侧主面板始终避让顶部数据与底部操作栏。输入框字号至少 16px，减少 iOS 聚焦输入框时的自动放大。

## 材质与定位标识

详情、列表、路线、天气、公告、手机导览共用的右侧主面板底色不透明度提高至 82%，仍使用 `LiquidGlassSurface` 的圆角、边框和轻微模糊。加载完成后初始就存在的品牌、顶部数据、底部导航、图例及工具框保持原来的材质参数。

人流区域标签改用公共组件第 4 款材质（9% 底色、2px 模糊、14px 圆角），保留区域名及人数。当前终端可见胶囊和所有类别的可见点位圆标统一由 `--pin-diameter:36px` 控制高度和直径；此前仅让胶囊与其内部图标等高，没有与其他点位统一，现已纠正。胶囊没有额外上下边框或内边距撑高，选中描边不改变几何尺寸；外层仍保留 56px 高的透明触摸热区，各视图及分辨率使用同一规则。

## 页面缩放的拦截范围

viewport 指定初始／最小／最大缩放为 1，禁用 user scaling；页面禁止双击放大及双指页面捏合，拦截 Ctrl/Cmd 加减号、0、滚轮页面缩放和 Safari gesture 缩放事件。保留事件传播给沙盘控制器，普通滚轮、鼠标点击拖动、单指滚动及键盘导航不被禁用。

网页不能强制覆盖浏览器菜单、既有站点缩放、浏览器无障碍设置或系统级放大。要求终端在所有情况下锁定页面比例时，须由部署设备使用受控浏览器／自助终端策略，并从 100% 页面比例启动；本轮没有增加设备管理后台或替用户修改浏览器设置。

## 镜头与卷轴

游览旋转中心固定为世界坐标 `[0,2,2]`。详情期间允许临时以设施为中心；关闭详情、点空白、再点当前设施时回到进入前的视角。若返回动画中途被拖动、滚轮或缩放打断，清理残余设施位移，恢复固定中心，避免下一次游览围绕设施转。

“看全景”使用约 1.05 秒平滑过渡恢复默认距离、角度及中心，详情打开时同时关闭详情；减少动态效果设置下直接到达最终状态。卷轴与沙盘共用同一相机和投影矩阵，保持一致的透视关系。卷轴是沙盘下方的真实世界平面，保持固定世界朝向、基准位置和尺寸，不再追随相机转向，也不再根据镜头距离或设施中心补偿位置与缩放。磁悬浮摆件式交互：卷轴是底座，沙盘在上方独立自转或随单指／鼠标拖动旋转；相机不再绕整个场景转，卷轴不会随沙盘转动。详情放大及缩放仍使用共享镜头，卷轴自然移动、放大并保持一致透视。卷轴单独作为背景渲染。先绘制卷轴，再清空深度缓冲绘制沙盘及云雾，卷轴不会遮住水墨云雾；纸面自身的轻微风动保留，风动倾斜在卷轴局部坐标中计算，不与相机方位绑定。

## 开场固定卡顿修复

旧实现到第 0.5 秒才启动三维构建，恰好与卷轴刚开始展开重叠。现改为在 `loading` 阶段完成分批几何生成、绘画纹理准备、材质编译与首次离屏绘制（包括缓冲区、纹理和阴影预热），完成后才开始 6 秒可见时间轴。加载期间使用两条从屏幕左右边缘向中间延伸的水墨进度条，中间仅显示百分比，不再显示“正在生成景区沙盘”。百分比为实际阶段完成度：纹理 10%、地形 25%、道路 45%、植被 60%、设施 80%、批处理 85%、模型完成 90%、材质编译 95%、首次绘制预热 100%；地形和设施阶段随实际子项完成递增。它不是下载字节占比或定时假进度，100% 短暂显示后开始展开，不播放一段再停住；后台等待不计入动画时长。窗口隐藏暂停时间轴，减少动态效果直接进入准备完成的静态构图。

## 回归范围

`tests/e2e/touch.spec.ts` 覆盖 1920×1080、1366×768、1180×820、1024×768、768×1024、960×600 触屏视口，单指滚动及旋转、面板边界、手机导览入口、胶囊几何、材质参数、鼠标保留、缩放拦截、返回打断、卷轴共享透视及背景层与“看全景”过渡；390×844 仅检查可打开及导航。`tests/e2e/scroll.spec.ts` 验证慢准备阶段不提前播放、预热后再展开、隐藏暂停和降级。

自动化使用 Chromium 触摸设备仿真；它不等同于所有实体平板或 Safari 的实机验收。最终设备浏览器的系统缩放策略按上方边界配置。

实测补充：本机 Chromium 1366×768 最终版本记录起卷前 3 秒的 179 帧，所有可见动画帧开始前预热均已完成；最大帧间隔与 95% 帧间隔均约 16.8ms，没有超过 40ms 的慢帧。该记录证明原固定构建卡点已移出可见动画，不代表所有设备恒定达到相同帧率。

### 本轮验收结果

2026-09-12：61 项单元测试、类型检查和生产构建通过；30 项游客端浏览器用例分组验证通过，5 项公共组件浏览器测试通过。慢准备等待使用与其他开场用例一致的 30 秒上限；此记录对应前次归档。后续透视纠正采用固定世界平面，回归检查风动暂停时世界变换在详情、旋转、缩放及返回期间不变，而四角屏幕投影随详情平移、缩放自然变化；单纯旋转沙盘不改变卷轴投影（纸面自身风动除外）。

端口 5173 和 5174 保持运行。网页层面的缩放限制与设备级缩放策略边界见上文。

本次纠正复验：类型检查、生产构建及 12 项触屏／卷轴浏览器回归通过；六种触屏视口、四种视图下，当前终端胶囊可见高度与所有可见点位圆标直径均为 36px。另在 1920×1080、1366×768 检查全景、望岳台详情、拖动旋转及返回，确认共享透视随镜头变化，返回中心与默认距离正确。构建仍有既有 Three.js 分包体积提示。

磁悬浮旋转实现：三维沙盘、路网、设施、选中圈及路线共用独立旋转组；游览围绕固定中心 `[0,2,2]`，详情拖动可临时围绕所选设施旋转。关闭详情时，镜头与沙盘姿态一同平滑返回，清除临时旋转带来的位移。点位／区域标签投影、详情焦点与模型拾取使用变换后的坐标，人流热力用逆变换读取景区原坐标，云雾朝向及阴影与旋转同步。保留鼠标、触控板与单指操作。

磁悬浮模块复验：4 项相关单元测试、17 项浏览器回归分组通过；41 个点位在 1920×1080 与 1366×768 旋转后逐一校验居中、单条连线及返回。游客端及公共包类型检查、游客端生产构建通过。“未开放”提示框复用 `LiquidGlassSurface` 第 4 款，底色 9%、模糊 2px、圆角 14px，已在两种桌面尺寸视觉复查。
