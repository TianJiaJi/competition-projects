## 公开快照字段与单位

| 字段 | 类型／单位 | 页面用途与未知规则 |
|---|---|---|
| `revision` | 数值版本 | 仅接收不早于当前版本的数据；演示为 Unix 毫秒时间 / 10000 向下取整 |
| `updatedAt` | ISO 日期时间 | 最近更新时间；界面时钟按 Asia/Shanghai 显示 |
| `parkOpen` | 布尔 | 开闭园说明，不替代各设施独立可用性 |
| `visitors` | 人，数值或 null | 实时在园，样例为九区域人数之和 |
| `parkingFree` | 车位，数值或 null | 三座停车场余位合计 |
| `weather` | 对象 | `label` 天气、`temperature` ℃、`humidity` %、`wind` 文本、`aqi` 指数、`ions` 个/cm³ |
| `points` | 点位 ID → 状态 | 可用性、忙闲、原因及设施明细 |
| `regions` | 区域 ID → 状态 | `availability/load/count/reason`；真实 0 显示 0，断线或 null 显示人数未知，关闭显示未开放 |
| `closedEdgeIds` | 道路 ID 数组 | 禁止使用的路段；不得仅凭视觉颜色判断通行 |
| `announcements` | 数组 | `id/title/body/pointId?`；公开公告，可关联点位 |

状态枚举：`availability=open/closed/maintenance/unknown`（开放／关闭／维修／未知）；`load=quiet/moderate/busy/unknown`（空闲／适中／拥堵／未知）。关闭及维修优先于忙闲。安全状态只读取可用性：绿可用、红不可用、灰未知。

### 卫生间、停车与索道字段

- `restroom` 可选：`totalStalls/occupiedStalls/availableStalls/queueCount`，非负整数或 null；分别为服务位总数、使用中、可用、排队人数。`female/male/maleUrinals/accessible` 为同结构四分项。合计包含小便位，不能称为坐蹲坑位总数。总数＝使用中＋可用＋暂停使用；各类独立排队。详情显示四类卡片，并可展开合计。缺失值显示暂无数据，真实零保留。
- `parkingCapacity/parkingFree`：停车容量／余位，单位车位。样例 P1/P2/P3 容量 700/500/300，营业时余位 128/96/64；闭园后余位恢复容量。停车场时段 07:00—20:00。
- `cable` 可选：`direction=up/down`；`cabinSeats` 人/厢，`cabinCount` 厢，`totalCapacity/directionCapacity` 人，`dispatchSeconds` 秒，`travelMinutes/waitMinutes` 分钟，`capacityPerMinute` 人/分钟，`opensAt/closesAt` 上海时分，`queueCount/inTransit` 人。详情中的在途仅本方向，全线容量不包含候乘者；未知不补样例数。下站显示上行、上站显示下行。
- 六类安全设施和四台终端使用相同点位状态体系；缺失状态为未知，关闭原因直接显示 `reason`。

### 固定样例与时间规则

基准快照实时在园 5461 人、停车余位 288；天气多云、23℃、湿度 68%、东南风 2.1 m/s、AQI 36、负氧离子 2840 个/cm³。区域人数及天气是演示常量；时钟、设施排队和营业状态按时间更新，不声称为实时实测。

固定不可用示例：镜湖及 Z5 养护关闭，峡谷卫生间检修，竹间驿灭火器和峡谷求助点检修；Z5 内设施继承区域关闭。公告为镜湖栈道养护通知。基准关闭道路数组为空；选路仍会校验目的地、经过区域及索道可用性。

开园样例时段 08:00—18:00。卫生间按分钟资源桶、索道按 10 秒步长从当日开门重算；容量、需求及清洁规则均见数值总文档。它们使用当前区域样例人数，尚非维护历史人口账本的服务端仿真。`alwaysOpen=1` 只在 sample 模式保持开放，实际营业时间外按演示中午计算服务负载；页面日期时间仍为真实上海时间，养护／维修示例保留。

## 终端与网址、接续参数

更换终端的操作步骤及四个可直接打开的示例地址见 [更换当前终端](../README.md#更换当前终端)。修改地址栏中的 `terminalId` 后按回车加载生效，不通过点击地图终端切换定位。

| 参数 | 规则 |
|---|---|
| `terminalId` | 仅支持 `terminal-entry/terminal-bamboo/terminal-summit/terminal-market`；分别为入口广场、竹间驿、山顶平台、归云集；缺省入口；空值或无效显示“终端编号无效，已使用入口终端” |
| `alwaysOpen=1` | 仅控制演示营业状态，不改变当前终端或时钟 |
| 手机二维码 `point` | 有效点位 ID，接续地点详情 |
| 手机二维码 `from/to/mode` | 实际选定的有效起终点 ID 和 `walk/cable`，不强行换成当前终端；由共享接续函数生成 |

每次刷新进入游览，不持久化模式。当前终端以高亮圆标与“我在这里”形成胶囊，胶囊高度及所有点位圆标直径统一为 36px（外围保留 56px 透明触摸热区），在所有模式中保留。点击其他终端只查看详情；手动改路线起点不改变设备定位。初次及每次新建导览、120 秒空闲重置后默认从当前终端出发，最后 10 秒提示重置。

`VITE_DATA_MODE` 默认 sample；live 使用同源 `GET /api/public/snapshot` 和 `/ws`。样例每 10 秒刷新；live 请求 8 秒超时，轮询间隔 10 秒、失败后每次加 5 秒、最高 30 秒；WebSocket 事件触发重新读取快照。断线保留故障提示，不回退样例数据。服务端尚未实施。

`VITE_MOBILE_URL` 仅在手机导览实际存在后配置，二维码白底。未配置时提示未接入，不生成无效链接。本轮不增加终端部署变量。

## 视图、卡片、运镜与路线

- 底部并列景点／设施／路线及游览／人流／卫生间／安全按钮，不显示“视图”标题；模式互斥，再点当前模式无操作。普通控件用玻璃预览 4，点亮用 3；大容器用 1。
- 游览显示景点、停车、索道、补给、出入口和终端；人流显示区域热力与人数；卫生间仅卫生间，安全仅安全设施。后三种模式仍保留当前终端。卫生间及安全模型有状态颜色，其余景物呈浅灰、低饱和的淡色。隐藏图标也不能通过三维拾取打开。
- 切换模式清除详情和路线，从列表选择自动进入对应模式。选中所有类别点位都以约 1.05 秒运镜居中放大；再次点当前点位、点空白或关卡片返回首次进入前的镜头，连续换点不覆盖原镜头。缩放按钮位于左侧，以动画调整并累积目标距离。默认视角立即自转，拖动／焦点／运镜时暂停；减少动态效果设置下静态切换。
- 同时一个主面板、最多一条连线。详情从当前点位连卡片；景点／设施列表和路线从底部对应按钮连卡片。卡片接入点固定为左边缘与屏幕高度中点，不随卡片内容滚动。
- 1920×1080 下卡片宽 360px，1366×768 下 330px；上方与右上数据组保持至少 16px，长内容内部滚动，避开底部导航。列表、天气、公告等开关不改变沙盘构图；详情按上述要求运镜。品牌组与四个顶部数据共用第 4 款框。
- 公共 `ScenicMap` 输入 `viewMode/currentTerminalId`，并提供区域投影、`focus/restoreFocus`、`blank`。旧 `heat/showToilets/filter` 仅在未传新模式时兼容。浏览器工具 `configure_scenic_view` 遵循相同筛选，支持 `viewMode/pointId`，兼容旧 `heat`，不得与 `viewMode` 同传。
- 路网静态 JSON 保存完整路径。`length` 为展示米数，坐标为示意世界单位；步行边默认双向，`directed=true` 单向。当前索道导航边为上站到下站的下行边；上行站可以展示排队数据，不代表本轮增加上行路线模板。道路关闭、区域关闭、目的地不可用、索道停运都会拒绝不可行路径。设备检修不自动封闭共享步道。
