# 部署材料目录

本阶段只有架构说明，没有 Dockerfile、Compose、Kubernetes、穿透或真实环境配置。

后续按以下用途分组创建：

| 分组 | 内容 |
| --- | --- |
| 镜像构建 | 五端共用的构建模板、后端镜像定义 |
| Compose | 本机整套联调、现场独立备用及入口代理 |
| Kubernetes | 基础配置、现有内网集群差异配置、kind 差异配置 |
| 香港入口 | Caddy、frps 和证书持久化规划 |
| 内网穿透 | node2 上独立管理的 frpc |

真实凭据和环境配置不提交；后续模板与数据卷规划按 [架构方案](../docs/工作区与容器编排架构-V1.0.md) 执行。
