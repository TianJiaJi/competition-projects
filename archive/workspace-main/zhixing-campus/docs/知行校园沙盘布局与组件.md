# 知行校园空岛沙盘

5500 公共大屏、5501 运行监控、5505 组件预览共用独立校园模型。00 的视图顺序为 **学习／生活／安全**，每次刷新默认学习。校园项目可以独立运行，不从景区或小区目录导入运行时代码。

## 最终空间与地形

整体由大圆主校园和较小的东侧附属组团错位相接，圆周有凹口、肩部和外伸台地，不是正圆或方形底盘。小圆不承载全部生活设施。空岛下部为破型的倒圆台，保留不规则底面、分层岩壁和少量长短不一的钟乳石。

地形先于建筑定义。北部山脊、山脚缓坡、中央鞍部与低处湖岸共同形成连续高度场；建筑按地形重新落位，仅在建筑脚下进行局部整平。相邻建筑统一组团朝向，不同组团沿等高线错位，避免整齐铺满和逐栋随机旋转。体素高程用于表现山脚校园，不作为工程施工标高。

| 设施组 | 布置 |
| --- | --- |
| 学习设施 | 明理楼、致远楼、博学楼、笃行楼共四栋教学楼；中央图书馆与东侧科创中心独立设置 |
| 学生公寓 | 四大栋、共十二个子栋；每大栋三个相连子栋围成南向开口合院。主校园北侧两栋，东侧附属台地两栋，均为六层 |
| 教师宿舍 | 一栋五层建筑，位于北侧独立庭院 |
| 体育设施 | 西侧八道 400 米跑道，内置足球场；独立体育馆在北侧，室外篮球场在南侧 |
| 生活设施 | 食堂、学生活动中心、便利店与快递服务站分布在低处生活区；独立礼堂位于南侧广场东侧 |
| 校园湖 | 不规则湖岸、完整环湖步道、临水亭廊；小桥两端落在实际岸上并接通步道，桥墩落至湖底 |
| 出入口 | 南侧学院式主门、东侧侧门，仅两处门区 |
| 小吃街 | 东侧门外八间店铺。车道在围墙内，墙外依次为步行街和店铺；整体由连续台地及岩体承托 |
| 停车 | 仅一个地下车库，入口靠东侧门内、位于礼堂周边；地面以步行与自行车为主，不设置汽车停车场 |

主干道采用深蓝灰路面、浅色路缘，步道采用浅色铺装。坡道为带完整路基的实体几何，底部嵌入地形；围栏立柱按实际体素地表落位。道路与店铺、建筑的占地关系由测试检查。

田径场与室外篮球场分别使用完整整平场地，覆盖跑道、球场和周边铺装。场地底座与地面采用共享标高，外围通过缓坡接回山脚地形，连接道路读取同一地形，避免原山坡穿入运动场。空间测试逐点检查两个场地的完整范围。

## 三类视图与水面

- **学习**：四栋教学楼、图书馆、科创中心。标点采用屏幕空间避让和锚点引线，避免六个标签挤在一起。
- **生活**：四大栋学生公寓、教师宿舍、食堂、活动中心、体育馆、礼堂、生活服务站、湖、田径场、球场、两门、小吃街和地下停车入口。
- **安全**：医务室、六处 AED、九处消防点、两处门卫、两处求助点、湖岸救生点及应急集合点。灰化其他环境，保留安全设施及医务室本色。

AED 覆盖图书馆、体育馆、北公寓、东公寓、食堂、礼堂；消防点覆盖图书馆、东西教学区、科创中心、两处公寓组团、食堂、体育馆和礼堂。新增点位属于场景说明，不生成虚假设备状态或业务记录。

湖水使用持续流动的波纹、变化法线、移动高光及岸边涟漪。减少动态效果时停止水面动画、自转并直接展示开场终态。浏览器测试对比水面区域的实际截图，验证正常模式有画面变化、减少动态效果时保持静止。

点击设施显示详情及连线，并平滑定位。关闭详情返回总览，详情打开期间暂停自转；普通交互后 20 秒恢复自转，手动暂停保持有效。

## 组件与数据边界

- `@scene/model/campus`：地形、校园布局、模型、水面、画卷、标点、投影避让及场景渲染器。
- `@scene/ui/campus`：公共 Vue 组件 `CampusMap`。
- `ModelBrowser`：统一页面包装、主题传递、设施详情和操作按钮。

`CampusMap` 参数包含 `palette`、`view`、`selected`、`showMarkers`、`intro`、`autoRotate`、`overviewScale`、`screenFraming`、`showLoadingProgress`；事件为 `select`、`blank`、`preparation-progress`、`intro-state`；公开方法为 `zoom`、`reset`、`focus`、`restoreFocus`、`setAutoRotate`。

00 开启分类和标点详情；01 保留原监控布局，仅替换模型；预览提供模型浏览。00 与预览保留画卷开场，01 直接显示终态。主题切换、缩放、复位、加载错误和资源释放沿用统一边界。

布局采用东为 +x、南为 +z。平面一单位对应四米，用于保持建筑、操场及跑道的相对比例；400 米跑道按第一道测量线计算，不能从体素车辆、人物或窗格推算业务容量。现有 B1–B6、F1–F7 等编号不变，宿舍报修关联第二大栋公寓，体育馆承接风雨操场与羽毛球馆记录。校园原指标口径不变。

## 验证

执行类型检查、全部单元测试、校园／公共大屏／监控端到端测试和构建。检查覆盖：占地与岛界、四个三翼合院、组内对齐、标准跑道、所有道路与店铺及建筑的关系、桥的两岸落点、安全设施覆盖、标签避让、水面动画、深浅主题、减少动态效果、图形上下文丢失及重进。
