# 通用应用搭建工作台与学校样例

版本：2026-10-12 · 固定画布、批量素材与成果入口修订。本文更新 v1 的流程与服务能力，保留 AI 工作流节点画布。04 的旧资料见 [历史方案](./历史方案/预制工作流-v1.md)，本轮不重新定义 04。

## 1. 产品与执行边界

5506 是通用“应用搭建工作台”。学校只是当前样例：学校名称、人物角色、需求提示、模板、固定初稿、一次调整、产物、预览和人工观察定义由样例包提供。通用页面不导入校园模型、实体编号或工单规则。

每段在输入材料后采用：**描述需求 → 自动细步骤 → 人工调整并确认 → 自动装配 → 成果预览与人工验收**。自由输入保存原文；结果来自预制脚本，不将输入伪装成任意 AI 能力。没有真实 AI 调用，也不现场生成源码和编译新项目。

03 的 SQLite、建表、参数化查询、业务写入与 HTTP 调用真实执行。天气、能耗、FAQ 为固定展示材料；业务状态不会重建三维几何。

## 2. 三段分工与交接

| 段 | 操作员 | 描述与一次微调 | 模板和交付 | 最新成果 |
| --- | --- | --- | --- | --- |
| 01 空间构建 | 1 号 | 完整地图、区域建筑、浏览方式；突出教学区、统一标识、学习视角 | 地图结构、空间映射、沙盘方案、调整记录 | 只有沙盘，保留缩放、旋转和设施聚焦 |
| 02 界面搭建 | 2 号 | 五端服务谁、做什么；调整职责、导航和首屏 | 页面方案、组件清单、给 03 的数据需求清单 | 五端全部现有页面，各自独立样例交互 |
| 03 数据与服务 | 3 号（SQL 负责人） | 表关系、查询、操作；拆分提交/处理人，完善关联与返回 | 结构、SQL、服务契约、初始化与调用记录 | 五端共享真实 HTTP 服务与 SQLite |
| 04 | 4 号 | 待定义，本轮暂缓 | 既有代码和资料保留 | 不阻塞 01—03 |

03 的讲解必须包含：接收与校验参数 → 校验角色、状态及归属 → 参数绑定与执行 SQL → 整理页面需要的返回结构。不能只说“封装接口”。

## 3. 界面与成果约定

页面以 HTML 常展开卡片＋SVG 连线为主体，无阶段分区框或节点侧栏。5506 复用校园公共包内的毛玻璃与等高线背景，原有配色不变，青岚项目不修改。保留“应用搭建工作台”标题及必要操作，移除英文副标题、样例名和流程口号；轮次与版本移至报告。

镜头完全手动：首次进入/新流程显示全图，刷新恢复本轮上次平移与缩放。自动运行、人工验收、内容改变不移动镜头。“定位当前”按全图失败（包括提交失败）→按路演顺序排列的人工停点→运行节点查找，无目标禁用。普通卡身、标题、正文、代码和空白均可拖动，禁止选字；输入框可编辑，按钮、链接、导入区、展开控件和滚动条保留操作。普通卡身滚轮平移画布，有实际溢出的卡内区域内部滚动；Ctrl/⌘＋滚轮缩放。

整体布局为空间居左、前端居上、数据与服务居右、自动总装居中，下方仅有测试和交付占位。默认摘要尽量在一屏 16:9 内阅读，1366×768 允许小范围拖动，不为塞满一屏过度缩小文字；节点按类型固定外框及底部操作区；长材料在固定区域内展开和滚动。内容改变不重排节点、不改变连线锚点。中间产物显示在节点输出区与具名连线上，不增设重复产物卡。

角色颜色为橙（空间）、蓝（前端）、青（数据与服务）、紫红（测试与交付），用于人工节点窄色条与连线；自动处理/执行节点使用独立灰白色条和灰色图标，不染负责人色。整卡中性底表示未运行/失效，蓝底表示运行/待验收，绿底表示完成；待验收停止动画，通过才变绿。失败显示红色边框和错误区。全部依赖线常显，主要交接产物名称常显，悬停节点突出相关上下游并显示名称。演示前端与地图素材不展示“预制”“模拟”“真实执行”等性质标签；实现方式保留在开发文档与导出记录。

七个输入节点使用同一份素材清单。提供可直接选择的本地文件夹和同结构 ZIP：地图 PNG、坐标 JSON、沙盘参考配置与参考图、五份通用页面 HTML、四份公共组件 HTML、SQL 与同源初始化数据、服务契约；M02 SVG 另列产物参考。HTML 包含有意义的页面源码片段、字段与表单，不是启动壳，不要求双击运行。详见仓库 `packages/demo/MATERIALS.md`。

整块导入区域可点击，原生选择多文件、拖放多文件；多次导入追加，按元信息去重，支持逐项移除。“载入参考素材”替换为完整参考清单。只登记文件名、大小、类型、修改时间等元信息，不保存正文或按任意文件生成项目；至少一份成功即可完成，不校验格式或数量。取消选择保持原状，清单不变不触发下游失效，移除最后一份返回待输入且保留历史与业务库。

自动步骤按依赖并行，由服务端持久化计时。普通节点默认 25 秒，复杂空间映射、页面装配、SQL 适配、字段接口映射与操作绑定默认 50 秒。当前并行关键路径约 525 秒（8 分 45 秒），SQL 和 HTTP 按实际返回完成，不为延时而伪造成功。卡片等待时显示任务，处理时逐步展示 3—5 条摘要，结束后才显示输出；前端展示最近摘要，完整过程在卡内展开。

自动展示时间嵌入操作与设计讲解，不额外叠加到 55＋5 分钟总预算。本轮只参考现稿及其历史分钟表，不修改或重排《新版路演与实操展示安排.md》。每人仍有需求、调整确认、成果验收三个主要停点。

分支和交接关系：

- 空间：需求后，轮廓→SVG、坐标整理、参考视角分析并行；汇合空间映射及沙盘方案，调整确认后生成沙盘并验收。
- 前端：接收已验收空间成果，需求→分端职责；组件匹配与导航布局并行；调整确认后分别装配页面和整理数据需求清单，汇合生成五端成果并验收。
- 数据与服务：接收已验收页面需求，需求→实体关系；表结构→SQL、参数校验→业务规则、返回契约分别整理，汇合参数绑定与方案核对；调整确认后修订产物并初始化数据库。这里并行的是方案设计，单次请求仍遵循校验→规则→SQL→返回。
- 中央总装：空间验收后先接收空间骨架并核对清单；页面验收后接入沙盘与页面；数据库就绪后对应字段接口并绑定操作；最后汇合跨端配置、只读连接检查、整体成果及第三人验收。中央早期工作可以与下一人的工作并行。
- 测试、交付继续占位，不代替第四人设计，不补造测试或交付通过记录。

导入立即显示选中文件与排队/提交状态；服务确认后标为已导入。选择、拖放和快捷载入共用串行提交队列，失败保留卡片错误与文件名供手动重试。普通轮询不会清除操作错误，旧响应不得覆盖已确认的新状态。同文件可重选，取消不改变状态。

验收卡常显端名链接：01 一个沙盘，02 和 03 各五个端；不常驻长 URL，不提供复制按钮，不将后几个端藏进滚动列表。状态和重试靠近入口。成果通过真实 URL 和独立命名窗口打开，不在浮层或 iframe 中展示。五端移除额外的阶段说明横条，保留正常工具区的刷新、空间聚焦、身份和错误反馈。窗口按 run＋stage＋terminal 复用，普通查看只聚焦。01 一直提供纯沙盘；02 一直提供五端本端样例；03 提供共享服务成果，不再把旧阶段自动跳转到最新阶段。每段只提供本轮最新有效成果，无历史运行快照。

验收通过、退回都必须有观察说明与时间；通过才允许下游交接，页面就绪本身不等于验收通过。退回回到本段调整。上游重新导入、提交需求或修改，使相关后续确认与检查失效，历史保留；初始化幂等，不隐式清空业务库。

旧版本尚无节点记录时，保留已发布产物并等待人工验收；已有节点图发生依赖变化时，相关确认与结果失效，保留需求、素材、数据库和历史，不补造新节点执行或人工通过。刷新及服务重启恢复节点进度，重复请求不重复推进；真实执行失败必须重试，不能由自动演示完成态覆盖。

## 4. 数据与业务范围

五端数据由统一访问接口切换：02 使用本端内存样例、刷新恢复；03 调用本机服务、刷新保留业务。

- 公共端：楼宇、设施、场馆、预约、公告、指标和空间详情。
- 监控：指标、安防、工单待办、设施状态和沙盘；沙盘明确使用当前服务记录。
- 手机：登录、设施与空间、公告、本人报修和预约、提交、取消自己的预约、查看处理结果。
- 后勤：工单及巡检的数量、列表、详情、领取、结果校验、完成历史。
- 管理：楼宇、师生、设施、工单、巡检、预约、公告、安防八类新增和编辑；不添加删除。

提交人为 `submitterId`，处理人为 `assigneeId`。关联使用 `facilityId/buildingId`；预约使用 `date/timeSlot/count`。领取不改变提交归属。完成要求本人领取且结果非空。服务拒绝不存在或不一致的引用，采用绑定参数而非拼接输入。

操作成功本端立即更新，其他端约 2 秒刷新。网络失败显示错误/过期状态，不使用样例数据掩盖失败。全部人物用角色或稳定编号，演示种子不含个人联系方式。

指标保留既有口径：在用空间为楼宇 used 总和；有效预约为全部“已预约”；后勤待办指标统计未完成工单，后勤首页同时列工单与巡检；设备在线率为正常设施占比。未按日期过滤的预约不称“今日预约”。

## 5. 持久化、身份与检查

本机服务位于 5507，只绑定 localhost；普通五端入口保持无服务依赖的原行为。演示账号预填，操作者点击登录；服务验证角色和操作权限，仅提供演示角色会话。

当前 run、输入、阶段、历史及会话存入 `.local/builder/current.json`；03 数据库为同目录 `run-<run>.sqlite`。同轮刷新、重开和服务重启恢复数据。身份按应用及 run 存在标签页 sessionStorage；同窗口刷新保留，关窗后重新登录。

“开始新流程”删除上一轮专属演示库，归档上一轮过程 JSON，建立新 run；旧成果链接失效。不会扫描或删除其他数据库。上游调整使下游失效但不会隐式清空业务库；重新确认 03 会执行幂等初始化并保留已有记录。

桥接只传样例、素材版本、run、stage、页面身份以及就绪/复位/确认，不传业务数据。校验 origin 和窗口 source。需要身份的页面登录后才能确认就绪；20 秒超时后显示重试。

D01—D05、B01—B05 在独立内存 SQLite 副本执行，包括真实关联查询、错误引用拒绝、结果适配、匿名化、外键、领取和完成前置条件、提交归属及取消权限。D02 分别说明“错误输入被拒绝”和“拦截断言通过”。

H01—H05 默认待核验，通过和失败均须有说明及时间。JSON 导出包含轮次、版本、输入、产物、执行、检查、人工观察和失败历史。自动通过不等同于人工完成；真人排练另按 [运行与排练记录](./校园演示运行与排练记录.md) 登记。
