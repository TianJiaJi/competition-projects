# 智慧景区 AI 协同运行架构图

用于深青色或深色答辩 PPT，展示理想运行架构，不标注功能实现状态。

- `智慧景区-AI协同运行架构.svg`：透明背景矢量版，文字已转为轮廓，优先用于 PPT 插入和缩放。
- `智慧景区-AI协同运行架构-透明.png`：3840 × 2160，RGBA 透明背景，可直接插入 PPT。
- `智慧景区-AI协同运行架构-深色预览.png`：深青底预览，便于查看实际展示效果。
- `source/智慧景区-AI协同运行架构-文字可编辑.svg`：保留文字对象的编辑源文件，使用 Heiti SC / PingFang SC 字体。
- `source/build_diagram.py`：SVG 生成脚本，依赖 fontTools 和 macOS Heiti SC 字体。

推荐 PPT 底色为 `#101F22`，等比缩放，避免拉伸。透明版仅模块有填充，画布背景完全透明。

主线讲解：现有系统提供运行数据，运营监测智能体识别异常、研判风险，并调用业务服务推送告警和建议；人员安排与执行处置，结果回写后进入持续监测。问答和内容审核为独立支路，三个智能体共用大模型、知识库与业务工具。
