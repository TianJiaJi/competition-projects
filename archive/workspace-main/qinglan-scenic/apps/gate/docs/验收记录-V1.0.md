## 使用与后续边界

本次常开预览位于 `http://localhost:5188/`；5177 已被游客手机端占用，未终止该进程。项目默认 `pnpm dev:gate` 仍使用 5177 且 strictPort；可通过 `pnpm --filter @scenic/gate exec vite --host 0.0.0.0 --port 5188 --strictPort` 使用备用端口。

现有管理员源码未由本任务修改，工作区其他未提交修改保留。接口为独立 OpenAPI 3.1 JSON，已做 schema 与示例校验，未实际导入 Swagger/Apifox。

仍待后续：真实手机 Safari/Chrome 软键盘和安全区、局域网访问、真实 Cookie 权限与数据库事务、管理员 OA 页面、跨端同步及部署。当前服务仅提供本端 Mock，不声称这些能力已完成。
