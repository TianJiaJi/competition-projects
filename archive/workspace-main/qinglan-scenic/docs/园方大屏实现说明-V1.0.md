## 最终布局与材质

页首标题居中，左侧园区状态，右侧天气、业务时间及更新时间。顶部四项指标、在园趋势和索道/卫生间卡围合沙盘，外侧为区域承载/停车与当前告警/事件流。环境指标在沙盘左侧，今日告警处置卡在右侧浮层，不压缩沙盘。

“景区空间态势”标题居中，复用 LiquidGlassSurface；标题、环境与图例采用预览四号 14px 圆角、2px 模糊、9% 底色。环境、处置卡和左侧下方面板与上方图表间距 12px；沙盘和外侧信息距底 16px。处置卡宽 208px/184px、高 366px/352px（两种视口）。园方全页禁用文字选择。

默认墨青，浅色仅在开发预览切换：背景 #101F22、柔光 #203A3C、文字 #E7EFEB/#A3BBB5、关键数字 #83CBB6，告警蓝/琥珀/红。仅三维 canvas 应用 brightness(.82) saturate(.90)，文字与点位不受滤镜影响。切换不重建模型或重播加载。游客端、公共预览仍使用浅色默认。

## 加载与专注

公共 ScenicLoadingScreen 整合山形标志、景区标题、横贯屏幕的水墨进度、百分比和准备文字，园方与游客导览共用。园方四张图表及三维准备完成才达到 100%；外围包围式入场，沙盘/卷轴最后淡入，卷轴保留底座但不展开。减少动态效果直接就位；三维失败仍可读外围数据。

打开详情时外围退场，沙盘容器用 440ms 平滑扩展至全屏且始终可见，容器就位后镜头将选中告警定位至屏幕中央。详情固定右侧距顶/右 32px，宽 420px/360px，长内容内部滚动。当前告警与事件流先淡出，再改至屏幕左侧淡入；同一组 DOM 保留筛选和滚动位置。

关闭、Escape、点击沙盘空白恢复总览，外围从四周返回；不重载模型。快速切换取消过期定时器，以最后操作为准。公共 ResizeObserver 仅标记变化，在渲染帧内调整画布并立即重绘，避免尺寸变化露出空白帧。

## 人数容器、告警与紧急氛围

人数为面向屏幕的 DOM 玻璃容器，绑定固定岛屿坐标投影；没有三维牌面建模、透视拉伸、引线、动态分栏或告警避让重排。多数锚点位于地表以下，公共通行区在湖中央，山顶位置略抬高。侧背面用 76°进入/84°离开回差与 240ms 淡出避免闪烁，详情时隐藏。公共接口为 regionLabels / region-label-* 投影。

园方隐藏游客导览圆点、终端胶囊与对应拾取。告警同地点合并计数，最高级别着色，详情内切换；筛选影响当前圆点但不影响全园统计。完成后列表、聚合、历史与事件流更新，负载与设施状态独立。事件流默认静音、不弹窗、不自动运镜，翻阅时保留位置。

只要全园存在未完成紧急事件，页面四周持续显示红色水墨雾气，不受选择、关闭详情、筛选或历史查看影响；最后一条紧急事件人工完成才淡出。雾气不拦截鼠标，减少动态效果停用呼吸动画。

## 验收入口

主视口 1920×1080，兼容 1440×900；小屏保持文字大小并允许面板内滚动。命令：`pnpm typecheck`、`pnpm test`、`pnpm build:ops`、`pnpm build`、`pnpm test:ops`、`pnpm exec playwright test tests/e2e/scroll.spec.ts`。本次执行结果记录于归档 README，不将历史通过次数冒充本次结果。
