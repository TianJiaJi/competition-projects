## 实际 API 适配

机器可读契约为 [mobile-qa-local-v1.0.yaml](openapi/mobile-qa-local-v1.0.yaml)。完整 [景区契约](openapi/scenic-api-v1.0.yaml) 仍是后续各端接口规划，本地服务没有实现其中全部路径。

| 路径（前缀 `/api/v1`） | 当前行为 |
| --- | --- |
| GET `/health` | 本地配置状态，不暴露密钥 |
| POST `/auth/experience` | 创建七天体验身份，返回 token 和独立 qa runId，201 |
| GET/POST `/qa/conversations` | 当前身份会话列表/幂等创建；新建 201，重放 200 |
| GET `/qa/conversations/{id}/messages` | 所属会话完整历史，尚无分页，`nextBefore: null` |
| POST `/qa/conversations/{id}/messages` | `start/delta/sources/done/error` SSE；取消、失败留痕、重试与幂等重放 |
| GET `/knowledge/sources` | 需身份与运行标识的预置知识列表 |
| GET `/knowledge/sources/{sourceId}` | 沿用基线公开来源详情；未知来源 404 |

微信与 H5 共用 Bearer 身份，替代旧 Cookie 假设。除 health/体验创建/公开来源详情外，均需 `Authorization: Bearer …` 和签发的 `X-Run-Id`。本地业务 runId 与问答 runId 分离；重置清空本端 token，新问答重新签发，旧会话不会混入。其他身份访问会话返回 404，运行不匹配返回 409。

问题创建要求 `Idempotency-Key`，相同编号但不同内容返回 409；正在生成返回 409；中断后新请求编号加 `retryOf` 指向失败回答，不重复插入用户问题。正文最多 1200 字；每身份每分钟最多 5 次生成、同时一条；首增量 20 秒、总计 90 秒超时。

静态来源详情保留 id/title/kind/excerpt/version/url 字段。`live-snapshot` 是每次回答时截取的本地演示状态，随消息保存来源全文，不提供可冒充历史快照的全局静态详情。客户端只允许共享点位及状态枚举进入上下文，预约联系人/电话不会发送给模型。
