# 通透玻璃公共组件 V1.0（CSS 修订）

## 当前方案

2026-09-11 根据实测资源占用，将公共玻璃按钮从 WebGL 实时折射改为 **普通 DOM + CSS 通透玻璃**。保留 `@scenic/ui/liquid-glass` 导入路径及 `LiquidGlassButton`、`LiquidGlassScene` 名称。

默认组合：**14px 圆角 / 2px 轻微模糊 / 18% 底色浓度**。无颗粒噪点、无强磨砂；通过透出背景、细亮边、轻微渐变与内高光形成清透材质。18% 指基础填充层的不透明度，不包含上面的少量渐变反光。透明款默认底色浓度 8%；品牌款保留较深青绿底，优先保证白字可读。

按钮文字、图标和点击区域保持稳定。鼠标悬停不加下划线，改为 180ms 表面反光淡入淡出；键盘焦点保留清晰轮廓。这里没有真实光学折射，不再使用原来的“折射强度 24”。

游客端已使用共享容器和按钮：大容器采用预览第 1 款，普通按钮第 4 款，点亮状态第 3 款。

## 快速使用

Vue 3.5 应用依赖 `@scenic/ui: workspace:*` 后，按钮可以直接使用，无需场景、背景快照、主题文件或渲染器：

```vue
<script setup lang="ts">
import { LiquidGlassButton } from '@scenic/ui/liquid-glass';
</script>

<template>
  <LiquidGlassButton @click="openDetails">查看景点</LiquidGlassButton>
  <LiquidGlassButton variant="primary" :loading="saving" @click="save">保存</LiquidGlassButton>
  <LiquidGlassButton :blur="0" :tint-opacity="0.12">清透无模糊</LiquidGlassButton>
</template>
```

`openDetails`、`save`、`saving` 由业务组件定义。图标放入默认插槽；纯图标按钮需添加 `aria-label`。不要在按钮插槽中放入另一个按钮、链接或输入框。

需要自带背景的预览/工具区时，可使用可选场景容器：

```vue
<script setup lang="ts">
import { LiquidGlassButton, LiquidGlassScene } from '@scenic/ui/liquid-glass';
import landscape from './assets/landscape.jpg';
</script>

<template>
  <LiquidGlassScene :background="landscape" style="border-radius: 20px">
    <div class="actions">
      <LiquidGlassButton>开始游览</LiquidGlassButton>
      <LiquidGlassButton variant="transparent">查看地图</LiquidGlassButton>
    </div>
  </LiquidGlassScene>
</template>

<style scoped>
.actions { min-height: 300px; padding: 24px; display: flex; align-items: center; justify-content: center; gap: 20px; }
</style>
```

组件自带样式，不依赖游客端 CSS，不引入 Tailwind、React、Next.js 或其他 UI 库。

## LiquidGlassButton

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius` | `number` | `14` | CSS px；0 为直角，48px 高按钮使用 24 可形成胶囊 |
| `blur` | `number` | `2` | CSS 背景模糊半径，限制在 0–8px；0 会真正设置 `backdrop-filter: none`，不保留额外饱和度滤镜 |
| `tintOpacity` | `number` | surface: `0.18`；transparent: `0.08` | 0–1 的底色浓度，越小越通透；品牌款在此参数基础上保留较深青绿色 |
| `variant` | `'surface' \| 'transparent' \| 'primary'` | `'surface'` | 轻透浅底、更透明、青绿品牌色 |
| `disabled` | `boolean` | `false` | 原生禁用，不响应点击或悬停，关闭该按钮的模糊 |
| `loading` | `boolean` | `false` | 显示 CSS 加载图标，设置 `aria-busy` 并禁用按钮；不启动 JS 动画循环 |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | 默认不提交表单 |
| `refraction` | `number` | 无 | **已弃用、忽略**；为旧调用保留兼容，不会启用 WebGL |

- 事件：`click(event: MouseEvent)`，鼠标、触摸、Enter 和空格均通过原生按钮处理，不重复派发。
- 默认插槽：文字、SVG 图标等非交互内容。
- `id`、`class`、`style`、`title`、`aria-label`、`name`、`value`、`form` 等属性透传到原生按钮。
- 组件 ref：`focus()`、`blur()`。
- `--glass-text-color` 可覆盖文字色，例如深色背景上设置为 `#fff`；默认浅底/透明款为深青色，品牌款为白色。
- `data-glass-mode="css|plain"`：表示该按钮是否请求背景滤镜。浏览器不支持滤镜时，CSS 自动忽略滤镜声明，仍保留底色、反光和边框。
- 禁用和加载状态无悬停高光；触摸设备不启用持久悬停。减少动态效果设置下，高光立即切换，加载图标停止旋转。强制颜色模式使用系统按钮颜色并关闭滤镜。

## LiquidGlassScene

场景现在只负责可选背景图及对子按钮的“关闭模糊”设置，不注册按钮、不测量布局、不绘制内容。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `background` | `string` | `''` | 可选普通图片 URL，`object-fit: cover` 居中铺满；缺省时使用浅青底色 |
| `disabled` | `boolean` | `false` | 为后代按钮关闭背景滤镜，保留通透底色和所有操作 |
| `maxDpr` | `number` | 无 | **已弃用、忽略**；CSS 版本没有画布像素比 |

- 默认插槽，也可通过 `#default="{ status }"` 读取模式。
- `status(value)`：初始化及模式变化时发出 `'css'` 或 `'plain'`。表示请求的样式模式，不表示图片是否加载完成或浏览器是否支持滤镜。
- `error(error: Error)`：背景图片失败时通知宿主；背景区域保留浅青底，按钮继续可用。
- `refresh()`：为旧代码保留的空操作，普通布局会由浏览器自动更新。
- `retry()`：重新挂载背景图片以重试加载。
- `data-glass-status`：与插槽/事件模式一致。旧的 `webgl/loading/fallback` 状态已移除，使用状态判断的宿主需更新。

## 与旧版的差异

| 项目 | 旧 WebGL 版 | 当前 CSS 版 |
| --- | --- | --- |
| 绘制 | 自定义画布、着色器、多级纹理缓冲 | 普通按钮与浏览器 CSS 合成 |
| 背景来源 | 显式传入的背景纹理 | 按钮背后实际页面内容，受浏览器背景滤镜规则约束 |
| 是否需要 Scene | 正常折射模式需要 | 可选，按钮能直接独立使用 |
| 拖动形变 | WebGL 弹簧 | 已移除；原生点击与表面高光 |
| 折射参数 | `refraction=24` | 接收旧参数但忽略 |
| 通透度 | 默认 surface 底色约 78% | 默认底色 18%，可通过 `tintOpacity` 调节 |
| JS 帧循环、布局观察 | 渲染调度、ResizeObserver、MutationObserver | 无 |
| 外部图片 | 采样需匿名 CORS | 按普通 `<img>` 显示，无画布像素读取需求 |

不再需要把 DOM 或沙盘截成图片来表现背景玻璃。直接叠在沙盘上时，由浏览器合成局部背景模糊；这不等于读取或折射沙盘纹理。祖先上的 `opacity`、滤镜、遮罩等可能改变 backdrop 的采样边界，正式布局中仍需检查效果。

旧 WebGL 源码与许可证已移至 [实验归档](../experiments/liquid-glass-webgl/README.md)，不再从公共包导入，不参与应用构建和工作区类型检查。归档保留原作者及 Apache-2.0 说明。正式 CSS 组件不包含这些渲染算法。

## 资源与可读性

- 无 WebGL 上下文、着色程序、场景纹理、背景上传，也无组件自己的 `requestAnimationFrame`、布局观察器或逐帧指针跟踪。
- 这不表示 CSS 毛玻璃零 GPU 成本：动态沙盘后面的模糊仍需浏览器合成。大面积、重复叠加和大量控件应避免；性能优先时传入 `blur=0` 或给场景设置 `disabled`。
- 边缘使用单层 1px 淡白描边，不叠加白色内描边；悬停保留表面反光，不增加边框厚度。
- 悬停只改变一层局部高光的透明度，不动画化模糊半径、滤镜或布局尺寸；静止时无组件 JS 循环。加载图标是仅在 `loading` 状态出现的 CSS 旋转。
- 不加噪点纹理，不用 20–40px 的强模糊制造磨砂感。较低底色让景物轮廓透出；高细节背景下仍需选择合适文字色或提高 `tintOpacity`，透明款不能自动保证任意背景对比度。
- 正文、表格和二维码继续使用稳定阅读面。通透按钮不替代这些内容容器的可读性要求。

## LiquidGlassSurface

从 `@scenic/ui/liquid-glass` 导入。非交互容器，与按钮共用 `material.css`，支持 `as`（默认 div，可设 aside、section、nav）、`radius`（14）、`blur`（2）、`tintOpacity`（0.18）。属性和事件透传到实际元素，内容放入默认插槽；可包含按钮和输入框。遵循 `LiquidGlassScene` 的 plain 模式，不增加渲染器或动画循环。

```vue
<LiquidGlassSurface as="aside" aria-label="导览详情">
  <LiquidGlassButton variant="transparent" :tint-opacity="0.09">普通操作</LiquidGlassButton>
  <LiquidGlassButton variant="primary" :tint-opacity="0.09" aria-pressed="true">已选中</LiquidGlassButton>
</LiquidGlassSurface>
```
