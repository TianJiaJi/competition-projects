# 组件来源与交互基线

来源：青岚山境整理提交 `5438b2d`。原景区在该提交后保持独立，新场景不引用它的路径。

## 保留内容

`packages/ui` 的液态玻璃、唱片架、滚动条、等高线、加载和图表源码由原包提炼；`packages/scroll` 保留卷轴时间线；`packages/model` 保留占位模型与镜头实现；`packages/contracts` 仅供保留的渲染器类型兼容，不引入网络客户端。包前缀从 @scenic 改为 @scene。

唱片架默认 duration=260ms、damping=18、wheelStep=100、settleDelay=180ms、parkDelay=200ms、snapEpsilon=0.002；玻璃默认 radius=14px、blur=2px、tintOpacity=0.18。项目主题在宿主覆盖，不改写这些运动参数。

表单的 TextInput 和 StatusTag 源自原后台；新列表/抽屉去掉原业务流程注入，保留同样的交互职责。移动端复用原 uni-app 栈、Lucide PNG 方案和等高线纹理。

## 验证

复用原单元测试覆盖唱片架阻尼、边界、吸附、曝光与间距、滚动条几何、原生滚动适配、镜头运动和卷轴时间线。浏览器检查加载、旋转、缩放、复位、详情、表单、任务处理及多个显示尺寸。

视觉基线由原组件源码、原景区已有截图与新前端实拍对照。新场景有意重组业务页面，保留字体、材质和交互基础，不要求新业务页面与旧景区逐像素一致。当前截图与测试产物放在被忽略的 `.local/qa`、test-results，不作为源码资源。

组件预览运行 `pnpm dev:ui`。保留的子目录 README 是详细组件 API 参考，其中历史景区业务说明不属于本轮实现范围；实际启动和替换方式以本项目根 README 与模板替换指南为准。
