# 教学预约演示规则

本机演示，非生产认证或教务系统。`user01 / 123456` 是 2024级软件工程1班学生林悦，`staff01 / 123456` 是带班教师陈越。教师仅审核本班学生的教室预约和请假；`admin01` 只能查阅预约，不能审核。历史预约缺新字段时显示“未填写”，按已知申请人映射班级；无法确定归属的旧申请只在管理员只读列表显示。

## 教室预约

- 教室来源于正常开放的研讨/教学空间。展示位置、容量、设施、开放规则；三档 `09:00–10:00` / `14:00–15:00` / `18:00–19:00`。日期为上海时间今天起 14 天（含当天），当天已开始的时段不可提交。
- 必填：教室、日期、时段、活动名称（2–50字）、用途（2–200字）、人数（1 至容量）、联系人电话（11位手机号）；补充说明可选（最多 200 字）。申请人由演示登录身份确定，班级从名册映射而非表单自报。
- `pending → approved | rejected | cancelled`；`approved → cancelled`；拒绝/取消不可再流转。拒绝原因必填。占用的已通过时段不可申请；不同学生的待审核竞争可并存，最终审批时再次检查占用。重复提交本人同教室同日期同时段有效申请返回冲突。教师审核仅限自己班级；取消仅申请人本人。
- 列表可查询日期/教室可用性；API 不允许任意调用者伪装成生产认证身份，仍需在部署前替换为真实服务端身份校验。旧 JSON 中仅 `purpose` 的记录照常展示，缺少新字段不阻断读取。

## 学生请假

- 表单参考学校请假表的分区/字段行：去向信息、请假信息、抄送人。是否离校必选；离校时是否离开学校所在地、去向（医院就诊/回家/校外办事/其他）和详细地址（2–120字）必填；不离校则无需去向/地址，服务端不存残留的去向资料。
- 紧急联系人姓名（2–30字）与电话、本人的手机号（均11位手机号）分别填写。请假类型（病假/事假/其他）、性质（日常请假/节假日请假）、事由（5–1000字）、起止日期时段必填。抄送人选填，本轮支持带班教师；必须确认填写信息真实有效。
- 起止日期通过月历弹层选择（今天起 30 天内），点击下一步后进入时、分、秒三列滚轮菜单（24小时制，时00–23，分/秒00–59）。可切换开始/结束时间，返回日历保留草稿；仅点击完成才更新表单，关闭不保存。自动按真实起止时间计算天、小时、分钟、秒。结束必须严格晚于开始，开始不可早于当前时间。同一学生待审或已通过的区间不可重叠，首尾时间完全衔接允许提交。
- 新记录保存 `startTime` / `endTime`，不再保存上午/下午。旧版 `startPeriod` / `endPeriod` 记录仍兼容读取：上午起点00:00:00、下午起点12:00:00，上午终点11:59:59、下午终点23:59:59，校验时保留整个旧时段。缺其他新增字段时显示未填写。
- 学生点击服务记录中的假条可打开独立详情页，查看完整表单、当前审批节点、审核说明及操作记录；支持刷新获取最新状态。当前实际流程为“学生提交 → 带班教师审核 → 本人返校核销 → 流程完结”，不会虚构学院或校级审批节点。
- `pending → approved | rejected | withdrawn | cancelled`；`rejected → withdrawn`；`withdrawn → pending（修改后重提）| cancelled`；`approved → completed（核销完结）| cancelled`。取消和核销完结均为终态；已通过不能直接修改，应取消后重新申请。拒绝原因必填。
- “撤回修改”先将原申请保存为 `withdrawn`，暂停教师审核，再将原表单带入编辑页；被拒绝时也可修改重提。重新提交必须重新确认真实性，并执行与新申请相同的全部字段、未来时间及重叠检查。重提沿用原申请编号，进入待审核，旧审核结果清空但操作历史保留。未重新提交的输入修改只在当前编辑页内，不视为已保存。
- “取消申请”表示本次假条不再使用；“核销假条”表示本人确认已经返校或结束请假并正常完结。核销仅对本人已通过的申请开放，需要二次确认，服务端记录 `completedAt` 和 `completedBy`，保留原表单、审批信息及操作历史。核销后不能重复核销、修改、重提或取消，已完结区间不再参与有效请假冲突检查。教师端支持筛选和只读查看已完结记录。本机演示采用本人确认，不校验定位、人脸、门禁或实际返校事实，核销时间取服务端操作时间。
- 每次流转保存版本号和提交/撤回/重提/通过/拒绝/取消/核销完结的实际操作者、时间与拒绝原因；旧记录仅依据已保存字段补展示已知事件，不虚构缺失时间。教师端提交当前版本号，旧版本审批返回冲突，必须重新读取新表单后审核。
- 教师只能查看和审批本班学生的请假，学生只能查询详情、撤回、重提或取消自己的申请；上述身份仍是本机演示参数，不是生产鉴权。申请与历史存于独立本地文件，服务重启后保留，工作台大重置时一并清除。
