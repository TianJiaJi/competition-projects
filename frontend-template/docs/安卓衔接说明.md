# 安卓衔接说明

居民／师生手机端保留 uni-app、Vue 3.4 与 Vite 5 工具链，桌面组件使用 Vue 3.5 与 Vite 7。两者只共享无 Vue 依赖的领域规则和配置，避免两个 Vue 运行时造成状态响应问题。

- 使用 uni 原生 view、text、input、textarea、picker、image 和导航 API；原生构建无需改写业务页面结构。
- `src/platform/index.ts` 集中导航、返回、通知和图片选择能力。H5 的可访问性增强由条件编译隔离。
- 页面使用安全区间距、内部滚动及 textarea 的键盘避让；返回按钮调用 uni.navigateBack，无历史时回首页。
- manifest.json 保留 app-plus 配置，不填写虚构 AppID、签名、包名或权限。
- 所有资源为项目内文件，不依赖景区后端或外部字体服务；手机图标为本地 PNG，避免原生 WebView SVG 差异。

后续实际打包：在 HBuilderX 中导入 apps/mobile，按选用的原生工具链配置真实 AppID、安卓包名、签名和所需权限，并对齐依赖版本。随后真机验证系统返回键、软键盘、安全区、CSS 色彩混合支持与页面生命周期。必要时为旧 Android WebView 增加颜色回退。

当前交付只通过 H5 验证，没有执行安卓原生编译、真机验收、签名或上架，也不承诺仅修改签名即可发布。工作人员端仍是 Vue 移动网页，不包含安卓适配承诺。
