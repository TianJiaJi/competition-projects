# 辅助脚本

从工作区根目录执行：

- `node scripts/archive-visitor-data.mjs`：游客端数据归档，参数以脚本为准。
- `node scripts/archive-ops-data.mjs [输出目录]`：从当前园方 Mock 和统计函数导出六场景完整 JSON、静态区域/点位以及 SHA-256 校验清单。默认目录为 `docs/archive/园方大屏-2026-09-12`；生成新版本时请传新目录，避免覆盖历史基线。重复导出应字节一致，不包含机器当前时间。

脚本不接入真实设备或数据库，不包含凭据。部署、数据库备份恢复、演示数据重置另设入口，不能混入归档脚本。
