# 管理员终端归档与对接说明

日期：2026-09-13。本期仅面向 PC 宽屏（1366×768、1440×900、1920×1080），不以手机或窄屏适配作为交付要求。应用：`apps/admin`（`@scenic/admin`）。本次按当前实现收尾归档，保留 15 个业务模块编号，游客与员工管理拆为两个独立页面。历史首版及审查记录保留，不将旧截图、旧测试数量或旧分支名称当作当前交付状态。

## 交付内容

- 修复唱片收起时品牌标识与全称截断，并修复三级目录取消浏览后恢复错误位置；统一唱片导航、公共玻璃控件、静态等高线背景及宋体标题；支持系统／浅色／深色外观，切换不丢草稿或业务状态。
- 管理列表统一固定标题、筛选、分页及内部阅读区；筛选浮层有独立草稿，返回列表恢复筛选和滚动位置。编辑、完整预览、确认窗与抽屉保持键盘焦点及未保存保护。
- 工作台以当前告警为主，预约概况和待处理举报为辅；举报可独立刷新。景区资料默认查看、显式进入编辑，保留封面比例和保存失败后的草稿；封面清单扩展为十幅共享景观素材，旧 ID 与路径保留。
- 游客 `#/users/visitors` 与员工 `#/users/staff` 分页；旧 `#/users` 兼容游客页。员工只读，游客禁用不影响订单、人数或禁言。
- 预约配额切换业务日期、类型、停车场后自动读取，仅接受最后一次查询响应；按唯一时段 ID 保存，次日不覆盖今日。
- 服务状态以七个健康环汇总后端、园区感知设备、导览、管理员、小程序、员工端和大屏。直接复用公共玻璃材质，深色健康／异常／未知区分；页面不显示数据来源标签、节点说明或描述性小字，不提供运维控制与明细。
- 旧内置文案按确定映射升级，保留订单、配额、revision 和业务数据。页面采用业务文案，Mock 来源及真实接口边界在本文件与接口文档说明。

## 接口与接入边界

本期为同浏览器本地业务原型，服务函数位于 `src/services/`。真实 HTTP、WebSocket、数据库事务、跨端同步、设备监测与部署尚未实现。页面可完整执行本地业务操作，不表示其它终端已同步。

| 对接内容 | 当前依据与要求 |
| --- | --- |
| 管理员完整接口 | [管理员后台接口文档 V1.0](管理员后台接口文档-V1.0.md)，覆盖鉴权、内容、预约、设施、检修、告警、用户、聊天、知识和服务状态 |
| 七模块健康汇总 | `GET /api/v1/admin/service-status` → `data: {source, checkedAt, modules}`；每模块含稳定 ID、健康／异常／未知计数及检测时间；本次已同步[公共 OpenAPI](../../../docs/openapi/scenic-api-v1.0.yaml)与[全局接口文档](../../../docs/智慧景区接口文档-V1.0.md) |
| 其它专项差异 | 专项接口文档 D-01—D-07 是设施全类型、卫生间分项、检修计划、新告警、筛选与关联读取的对接依据；公共旧 schema 尚未覆盖全部扩展，不能直接套用 |
| 员工只读 | 同一用户接口按 identity 筛选；真实后端必须拒绝员工禁用，并以用户 ID 关联订单，不能沿用样例昵称匹配 |
| 配额与写入安全 | 服务端重新校验业务日期、已结束档、剩余配额、幂等键及事务；本地保护不是服务端实现的证明 |
| 主题与阅读状态 | 本地 UI 状态，无需增加服务端接口；外观键为 `qinglan.admin.appearance`，不随业务数据重置 |

固定业务日期为 2026-09-12，业务时钟为 14:30，服务检测快照也固定；读取时间使用真实时间。后端接入后必须分别提供业务时间、检测时间和响应生成时间，不能用刷新伪造新的检测。
