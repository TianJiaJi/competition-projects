# 云栖雅苑空岛沙盘

社区沙盘由公共大屏、管理大屏和组件预览共用。四类住宅采用暖棕、砂金、米白的现代体素建筑，中央草坪与小水景连接东西两侧公共建筑。三维模型和底部画卷读取同一份布局。

## 入口与坐标

- `@scene/model/community`：Three.js 渲染器、布局、空间锚点与主题类型。
- `@scene/ui/community`：`CommunityMap` Vue 公共组件。
- `packages/experience/src/components/ModelBrowser.vue`：页面接入及玻璃工具按钮，三个页面共用。
- `packages/model/src/community/layout.ts`：空间位置唯一来源。`x` 正方向为东，`z` 正方向为南，地面 `y=0`；坐标为沙盘单位，不代表施工图米制尺度。

岛面约 100 × 84 单位，默认由南侧稍偏东观察；北侧楼房、中央花园、南侧别墅。6:4 是默认画面的楼房与别墅视觉权重，不是栋数、户数或用地指标。

## 业务关联与组件接口

`anchors` 保存稳定空间锚点及 `parentId`；`recordAnchor` 将现有设施、停车、预约、工单、巡检、公告和安防记录映射到锚点。F1/F2 等设备或空间保留业务编号，共址设施不生成重复建筑。未有业务记录的门区、取水点和生活中心采用独立场景编号。

`CommunityMap` 参数：

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| palette | 社区暖色主题 | 前端传入 `scenario.theme`；变更时更新模型和画卷 |
| intro | false | 是否播放约六秒的画卷展开、空岛浮现 |
| autoRotate | true | 是否自动旋转；减少动态效果时停止 |
| overviewScale | 1 | 取景留白倍率，越大越远 |
| showLoadingProgress | true | 是否使用组件内加载进度，页面包装使用全局加载遮罩 |

事件：`preparation-progress(number)`、`intro-state(ScrollIntroState)`。公开方法：`zoom(factor)`、`reset()`、`setAutoRotate(enabled)`。复位恢复默认相机、缩放与岛体朝向，不改变用户选择的自动旋转开关。

公共大屏和预览开启开场，管理大屏直接展示。保持现有加载进度到 100% 后再展示页面的流程。WebGL 或加载异常显示重试提示，离开页面会释放资源，重新进入会重建。

00 公共端支持设施标点、既有设施记录详情与平滑运镜；不增加实时设备着色、业务写入或完整室内/地下建模。01 和预览保持空间浏览。

## 本轮页面范围更正

气泡导航、通知气泡和设施标点详情仅接入 00 公共端（5400）。沙盘上的圆形设施标点使用主题实色底板；菜单、通知及详情面板保留磨砂效果。01 管理大屏保留原有运行面板；其他端不接入本轮气泡导航。景区子项作为只读视觉参考，保持归档，不修改其代码。

交互后等待 20 秒恢复顺时针自转；设施详情打开期间持续暂停，手动暂停需点击继续。

### 00 开场取景

以 5173 游客端的开场源码及截图为参考：卷轴横边与屏幕底边平行，展开后在第 3–6 秒随空岛升起平滑推进镜头。结束时提高沙盘画面占比，卷轴下沿约藏出屏幕高度的 1.75%。菜单、通知、信息卡、设施标点与操作控件均在 ready 后显示。此取景通过 `screenFraming` 仅由 00 开启，01 及预览保持现有取景；减少动态效果时直接展示结束状态。

00 的界面入场沿用景区 0.6 秒原位透明度渐入；展开面板采用 0.18 秒透明度过渡。复位及缩放按钮使用同一相机插值，复位同时平滑恢复岛体默认朝向。

### 00 UI 比例与按钮选中态

对齐景区游客导览在 1920 宽画面上的 64px 标题、20px 菜单文字及相应信息卡尺寸，使用视口宽度和上下限控制各尺寸；1100px 以下保留紧凑布局。公共 LiquidGlassButton 沿用 `primary / transparent` 变体，00 内将 primary 玻璃染为社区主题暖棕色，保留透明度、高光和背景模糊；主导航、子分类和通知选中态统一使用此机制。范围限定云栖 00。

### 连线、表面与喷泉

菜单、通知及设施详情使用共用 `BubbleLeader`，将触发按钮或设施标点边缘连接到气泡边缘，运镜、拖动及尺寸变化时更新，关闭后释放帧回调。Dock 气泡和设施详情互斥，切换时移除前一个气泡及其连线。

程序化体素按共面覆盖范围裁去重复面，保留未覆盖区域，修复平台与草地、岛底岩块、栏杆、立面及树冠重叠；未受影响体块保留实例化，裁切部分静态合批。透明玻璃逐片排序，避免整批实例的透明排序冲突。

原花园方池改为八边形石质喷泉，沿用现有位置与占地。八道弧形水柱配合移动水滴、池面光纹和落点扩散涟漪，减少动态效果时静止。画卷线稿同步更新；组件重建、卸载会释放喷泉几何及材质。

### 住宅与花园标点

00 沙盘显示单元楼 I–VI 栋（对应 B1–B6）、别墅 I 区（默认视角左/西侧）、别墅 II 区（右/东侧）及中央花园，名称常显。保留会客厅、健身房、东门、消防栓及停车标点；F4 电梯与 F6 照明保留业务记录和空间归属，但不再作为地图标点显示。区域介绍由布局派生，不新增业务记录。

标点采用预设两层屏幕偏移，层级在旋转和选中时保持不变，取消逐帧碰撞抬升和按选中状态重新排序。点击住宅或花园继续使用统一详情气泡、连线及平滑运镜。

### 00 视图分层

底部 Dock 按景区导览形式增加住房、公共、安全三个染色玻璃切换按钮，默认住房。住房层为 B1–B6、左右别墅 I/II 区及南侧小区大门（9 个标点，大门为圆形按钮）；公共层为中央花园、F1 会客厅、F2 健身房、C1–C3 停车场（6 个）；安全层为东门道闸 F3、西门道闸 west-gate、消防栓 F5，加上会客厅和生活中心入口处的两台 AED、东西区消防器材、东西门求助点及花园应急集合点（10 个）。每次只显示当前层，切层时关闭详情与连线；层内固定两层偏移，不做旋转中的避让跳层。西门沿用既有场景锚点与空间说明，不创建新的设施业务记录。

安全视图沿用景区材质着色机制，将非安全部分灰化，保留道闸、消防和急救设施本色。新增空间设施不生成业务记录。点击标点按区域体量推进镜头，细小设施采用更近取景；关闭或复位平滑返回。

每次刷新 00 均初始化为住房视图，不记忆上次分层和打开的详情。底部左右两组均为双字按钮，空间 / 服务 / 概况与住房 / 公共 / 安全共用响应式宽度、图标尺寸及间距。
